# Screenshots

Drop PNG files into this folder with the exact filenames below so the main
`README.md` image references resolve.

All screenshots at **1280×800** or larger so they also pass AMO's
screenshot sizing check.

| Filename | What to capture |
|---|---|
| `hero.png` | Opening shot — a paragraph of English text with one phrase highlighted in yellow marker, a word tooltip open nearby showing translation. Use real content (news article, blog) — not lorem ipsum. |
| `word-lookup.png` | Double-click a word; show the tooltip with translation, POS badge, meaning, and example sentence. |
| `phrase-toolbar.png` | A phrase selected with the dark floating toolbar (Translate / Highlight / ×) above it. |
| `phrase-translation.png` | The phrase tooltip after clicking Translate, showing a full-sentence translation in the target language. |
| `highlight.png` | A paragraph with two or three highlighted phrases; shows the hand-drawn slanted marker style over real text. |
| `highlight-controls.png` | Clicking an existing highlight; show the Adjust / Remove / × popover. |
| `options.png` | The Preferences page with API key field, language selectors, and model dropdown. |

Blur or redact anything personal (tabs, bookmarks, the actual API key)
before committing.

Optional: a short animated `demo.gif` (≤5 MB) of the full flow —
double-click → translation → select phrase → highlight → reload → highlight
survives. Record with Kap or CleanShot, convert to gif via `ffmpeg` or
`gifski`.
